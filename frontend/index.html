⚙️ Setup & API Keys

Configure Reddit and YouTube API access

🟠 Reddit API

Create a free app at reddit.com/prefs/apps → "create another app" → choose script.

🔴 YouTube API

Go to console.cloud.google.com → APIs & Services → Enable YouTube Data API v3 → Create API Key.

Free quota: 10,000 units/day (~100 searches/day).

📄 Create .env file

Save your keys in a .env file in the trend-tracker folder. They are never sent anywhere — only used server-side.
